# `mbr-envelope` (Rust)

Biblioteca pura (sem I/O) para construção, avanço de `trace` e certificação do Envelope Oficial do **Mercado no Brasil (MBR)**.

## Uso no `Cargo.toml`

```toml
[dependencies]
mbr-envelope = { git = "https://github.com/lisboajeff/mbr-envelope-rust.git", tag = "v1.0.0" }
```
